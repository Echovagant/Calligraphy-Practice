# 关于本项目

> 一句话：**一个能真正写、能真正存、能真正交流的在线书法练习台。**

---

## 它是什么

书法练习平台把「临帖 — 落笔 — 成篇 — 交流」这条完整的链路搬到了浏览器里：

- 打开就能写，不需要装任何客户端；
- 写完的字帖、作品、练习记录都跟着账号走，换设备接着写；
- 除了自己练，还能看到别人写的、比、评。

## 四个核心场景

**落笔** — 毛笔手感的练习台。笔刷有大小、颜色、硬度；**压感笔的笔压真实改变笔迹粗细**，鼠标则按运笔速度映射粗细；手掌搭在屏上不会误画。纸面是宣纸色，格线可切换方格、田字格与横线。撤销以「一笔」为单位，切后台或刷新回来笔迹还在。写完一笔，页面会给出该笔画的起笔、行笔、收笔写法与顿点位置。

**造帖** — 任意一段文字都能变成可打印的习字帖。选字体（楷 / 行 / 隶 / 篆 / 草）、布局（方格 / 竖排 / 横排）、每页字数、字号、纸色与格色，右侧实时预览，满意了直接下载 PNG。生成的帖子会存进账号，在「我的字帖」里随时调出来继续练。

**成篇** — 作品可以传上去进入公开画廊。画廊是服务端分页与检索，标题和作者都能搜，排序也能换。被审过的作品会带上浏览量、点赞与评论。

**交流** — 讨论区按分类和标签聚合，置顶与精华帖单独成栏，侧栏汇总热门讨论、活跃用户与热门标签。点赞状态存在服务端，不会刷新一次就丢。

## 适合谁

- 用平板配触控笔、想随时练字的初学者 —— 笔压与手掌误触都处理好了，不需要额外装客户端；
- 有一台电脑、想随时练字的人 —— 选字帖生成，比打印帖更省事；
- 有老师或社团，需要留档与点评 —— 作品与评论都带归属与记录；
- 喜欢在作品与经验之间来回看的人 —— 社区与画廊够用。

## 技术形态

| | |
|---|---|
| 前端 | Vue 3 + Vite + Element Plus + fabric.js（画布与作品存储）+ Three.js（水墨背景） |
| 书写输入 | 自研 Pointer Events 输入层：压感、笔／手区分、顿点检测、笔级撤销、草稿落盘 |
| 后端 | Spring Boot 3 + Spring Security + Spring Data JPA + JWT |
| 存储 | MySQL 8（用户 / 作品 / 社区 / 审核）、Redis（令牌黑名单与身份缓存）、本地文件（图片与头像） |
| 接口 | 一份 OpenAPI 3.1 契约作为前后端唯一真相源，56 个端点，构建期自动比对三方一致性 |

## 设计与体验取向

- **纸与墨的配色** — 页面底色是宣纸色 `#f4efe2`，主色取赭石 `#8B4513`，语义色（成功 / 警告 / 危险）也收在墨色家族里，不用刺眼的默认蓝绿红。
- **笔比鼠标优先** — 输入层按「输入设备」分档：压感笔与数位板是创作端，鼠标是降级方，手机端只读。手掌误触、笔压、顿点都在自己的代码里处理，不依赖第三方笔刷的行为。
- **水墨背景** — 全站用一块 WebGL 水墨山水做底，随滚动流动，只做气氛不抢内容。
- **字是主角** — 标题与正文字体走宋体系，作品区直接用书法字体渲染标题与正文。
- **键盘可用** — 交互元素能 Tab 到、焦点有可见轮廓，纯图标按钮带 `aria-label`，键盘能直接触发。
- **报错说人话** — 接口不可用时提示「无法连接服务器，请确认后端服务已启动后重试」，而不是把浏览器的原始英文错误丢给用户。
